Add your real photos here, named exactly as below. The site checks for each
one automatically — anything you haven't uploaded yet just keeps showing the
current placeholder tile, so you can add photos gradually with no risk of
breaking a page.

  hero.jpg              — Homepage hero image
  jethro.jpg            — Homepage "About Me" preview headshot
  jethro-about.jpg      — Full About Me page headshot

  portfolio-1.jpg  through  portfolio-12.jpg
                         — the 12 portfolio grid tiles (Portfolio page +
                           homepage preview use the same files)

Notes:
- Any image size/orientation works — photos are automatically cropped to
  fill their tile (object-cover), so a good starting point is anything at
  least 1200px on the longest side.
- Want more or fewer than 12 portfolio photos, or different captions /
  categories (family, couple, portrait, event) for each? Just ask — the
  list lives in lib/gallery.ts and is easy to adjust to match whatever you
  actually have.
- The Open Graph / social-share image and browser favicon are generated in
  code (app/opengraph-image.tsx and app/icon.tsx), so no file is needed for
  those.
